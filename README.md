# oDuuk's Skyblock Modpack
This is the modpack oDuuk uses for Skyblock, free for others to download and use.
The pack includes Duuk's Dungeons resource pack :)

## Instructions
Download the file called 'Duuk's Skyblock Pack 26.1.2.mrpack'
Follow [these instructions](https://youtu.be/7dnSROKAF5w) on how to use it in your Modrinth launcher if you need help installing it.
